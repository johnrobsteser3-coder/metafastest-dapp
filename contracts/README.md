## 📋 How to Verify Contract Source Code on BscScan

1. Open **[https://bscscan.com/verifyContract](https://bscscan.com/verifyContract)**.
2. In **Contract Address**, paste:
   ```text
   0xbC6AC29404f5E68ed9d4e340E286aAb265Ea6e0c
   ```
3. Compiler Type: **Solidity (Single file)**.
4. Compiler Version: Select **`v0.8.20`** (or matching `0.8.24` from Remix).
5. Open Source License Type: **MIT License (MIT)**.
6. Click **Continue**.
7. In the Solidity Code box, paste the code from [`contracts/MFHRCToken.sol`](./MFHRCToken.sol).
8. Click **Verify and Publish**.
9. Your contract will immediately receive the **Official Green Checkmark & Verified Status** on BscScan!
